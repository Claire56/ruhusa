## Design Rule

The LLM may propose an action, but it never decides whether that action is authorized.

## v0.1 Policy Model

The v0.1 `StaticPolicyStore` was intentionally small and deterministic. It existed to make authorization experiments easy to inspect.

The request/decision abstraction was designed so future policy adapters could call external policy decision points without moving authorization into the model.

## Historical Note

Later milestones added:

- continuous revocation
- task-bound delegation
- trusted grant provenance
- invocation provenance
- tool and implementation identity
- adversarial benchmark infrastructure

Those capabilities are intentionally not backported into this historical v0.1 snapshot.
